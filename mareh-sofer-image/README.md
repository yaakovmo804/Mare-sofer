# מראה סופר — אפליקציית שיפור תמונה עצמאית

גרסת בסיס עצמאית לשחזור וליטוש תמונות כתב סת״ם.

## עקרון העבודה

- צורת האותיות נעולה.
- אין שינוי של קוצים, תגים, חללים, עוביים או נטיות בתוך האות.
- השינויים חלים על איכות הצילום, חומר הדיו ומראה הקלף.
- יישור מסובב את התמונה כולה בלבד.

## יכולות בגרסת הבסיס

- טעינת תמונה מקומית.
- לפני ואחרי עם מחוון.
- פרופילים מהירים: נקי ונאמן, דיו שחור חי, ברק עדין, לק חי וקלף טבעי.
- חדות, הפחתת רעש, עומק שחור, אחידות מילוי, ברק, מסה במרכז הדיו, חום ומרקם הקלף.
- יישור אוטומטי ותיקון ידני ברבע מעלה.
- הצגת מסכת הדיו וייצוא PNG.
- PWA ועבודה לא־מקוונת לאחר טעינה ראשונה.

## הפעלה מקומית

יש להגיש את התיקייה באמצעות שרת סטטי, לדוגמה:

```bash
python3 -m http.server 8080
```

ולפתוח:

```text
http://localhost:8080/mareh-sofer-image/
```

## בדיקות

```bash
cd mareh-sofer-image
npm test
```

## המשך פיתוח

1. מברשת תיקון למסכת הדיו.
2. Undo/Redo.
3. תיקון פרספקטיבה בארבע פינות.
4. ספריית דוגמאות קלף מאושרות.
5. תיקון טשטוש תנועה והילות.
6. חיבור אופציונלי לשרת AI — שינוי חומר בלבד תחת מסכה נעולה.
7. אייקון והעברה למאגר עצמאי בשם `mareh-sofer-image`.
