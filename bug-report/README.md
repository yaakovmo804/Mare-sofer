# מראה סופר — דיווח תקלה בלחיצה

רכיב MVP עצמאי לדיווח תקלות מתוך האפליקציה.

## מה נשמר
- גרסת האפליקציה
- שם המסך הנוכחי
- הפעולה/הכפתור האחרון
- עד 10 פעולות אחרונות
- שגיאות `window.error` ו־`unhandledrejection`
- מצב חיבורים שמוזן במפורש על ידי האפליקציה
- הערה קצרה שהמשתמש מוסיף בזמן יצירת הדו״ח

## מה לא נאסף אוטומטית
הרכיב אינו קורא ערכי input/textarea, תוכן שיחה, שמות תלמידים, שמות קבצים או תמונות. `widget.js` עוקב רק אחרי לחצנים שנמצאים ברשימת allowlist מפורשת.

## בדיקות
הרצה מקומית אחרונה: **5/5 עברו**.

```bash
node --test bug-report/tests/bug-report.test.mjs
```

הבדיקות מכסות: מגבלת 10 פעולות, יצירת דו״ח, מסלול שחזור, לכידת שגיאות, העתקה ללוח ואיפוס היסטוריה.

## שער שילוב בטוח
האתר הפעיל „מראה סופר — טעימה ראשונה” נמצא ב־Sites בגרסה 80, אך Site projection אינו מספק כרגע קוד מקור שניתן ל־materialize. GitHub אינו המקור הקנוני העדכני של האתר.

לכן ה־PR נשאר Draft ואינו מתמזג ל־`main`. כשקוד v80 הקנוני נגיש, מפעילים תחילה את ה־widget במסך אחד בלבד ובודקים תקלה אמיתית.
