# טוב מראה — גרסת iPad

תת־אפליקציה עצמאית של מראה סופר לשיפור וליטוש תמונת כתב.

## הפעלה באייפד
1. לפתוח את `tov-mareh/index.html` דרך כתובת הפריסה ב־Safari.
2. ללחוץ על שיתוף.
3. לבחור **הוספה למסך הבית**.
4. האפליקציה תיפתח לאחר מכן במצב standalone ולרוחב.

## מבנה הממשק
- סרגל כלים שמאלי למגע.
- משטח עבודה מרכזי.
- פאנל מקצועי ימני.
- סרגל פרופילים תחתון.
- השוואת לפני/אחרי עם מחיצה נגררת.

## מנועים
- מנוע מקומי ללא רשת.
- שכבת חיבור למנוע AI דרך endpoint חיצוני.
- fallback מקומי כאשר השרת אינו זמין.

## סדר טעינה ובדיקת רגרסיה
`index.html` טוען במפורש `app.js` → `engine-v21.js` → `live-preview-v4.js`.
ה־Service Worker מחזיר כל קובץ כפי שהוא, מהרשת או מהמטמון, ללא שרשור מנועים.
כתובות הקבצים ברשימת המטמון צריכות להתאים לכתובות שב־HTML, כולל פרמטר הגרסה.
ניקוי מטמונים ישנים מתבצע רק בהפעלת ה־Service Worker ובתחום `tov-mareh-ipad-`.
שכבת התצוגה אינה מוחקת את המטמון המותקן או את המטמונים של הגרסאות המקבילות.

להרצת בדיקת הדפדפן משורש המאגר:
```sh
npm ci
npx playwright install chromium
npm run test:tov-mareh-loading
```
הבדיקה משתמשת בקבצים האמיתיים וב־Service Worker פעיל ב־Chromium. היא בודקת
טעינה ראשונה, רענון נשלט ורענון ללא רשת, כולל הפונקציות הפעילות, תגובת הסליידר,
תצוגה מקדימה ברוחב 720 פיקסלים ועיבוד מלא ברוחב 1800 פיקסלים.
הבדיקה רצה גם ב־GitHub Actions לצד `npm test`.
תרחיש נוסף בודק הפעלה ראשונה של שכבת התצוגה כשכבר מותקן Service Worker,
ומוודא שהמטמון נשמר גם להפעלה ללא רשת.

## מסלול החידוד
`app.js` מספק את `maskedUnsharp` ואת `boxBlur`. מנוע 2.1 מעביר לחידוד הקיים
את מסכת הדיו שכבר חישב לכל פיקסל, ושומר על מקדם החידוד 1.45 ועל סף ההפעלה הקיים.
אין מנגנון חידוד נוסף ואין שינוי בקוד הסיבוב, הפרספקטיבה, החיתוך או הדגימה מחדש.
מדד השינוי מחושב מתוצאת החידוד הסופית.

שכבת v4 עוטפת את `processLocalV21`, ולכן גם התצוגה המקדימה, „החל שיפור”, הייצוא
והגיבוי המקומי למנוע AI משתמשים באותו חידוד. נתיבי v4 ו־v5 טוענים אותם קבצים משותפים;
`engine-v5.js` מחבר בקרות ואינו מוסיף אלגוריתם עיבוד.

בדיקות הדפדפן משוות חדות 0 לחדות חיובית כאשר יתר ההגדרות זהות. הן מאמתות שינוי
בפיקסלי RGB, היעדר שגיאות JavaScript וקריאה אחת לפונקציית החידוד הקיימת.
הבדיקה הישירה מכסה חדות 2, 40 ו־100 וכן את מכפיל הגיבוי 1.12. בדוגמת הקווים
נבדקים גם מיקומי הדיו, העובי והחלל הפנימי, ממדי התמונה, ערכי alpha ושמירת המקור.
זו בדיקה על דוגמה סינתטית, ולא הבטחה שמסנן חידוד לעולם לא ישנה סיווג פיקסל גבולי בתצלום.
בדיקות הטעינה מפעילות את סליידר החדוּת ואת העיבוד המלא בחדות 40, גם ללא רשת.
בדיקת הייצוא קוראת את ה־PNG שהורד ומאמתת רוחב 1800 והתאמה לפיקסלים המעובדים.
נבדק גם מעבר אוטומטי למנוע המקומי לאחר תשובת 404 משרת AI מדומה מקומי.

תיקון במאגר ובדיקות מקומיות אינם פרסום ל־Sites. שילוב באתר החי דורש בדיקה
מול הקוד הקנוני שלו ופריסה נפרדת; התיקון הזה אינו משנה את סדר הטעינה של PR 23.
