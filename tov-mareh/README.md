# טוב מראה — גרסת iPad

תת־אפליקציה עצמאית של מראה סופר לשיפור וליטוש תמונת כתב.

## הפעלה באייפד
1. לפתוח את `tov-mareh/index.html` דרך כתובת הפריסה ב־Safari.
2. ללחוץ על שיתוף.
3. לבחור **הוספה למסך הבית**.
4. האפליקציה תיפתח לאחר מכן במצב standalone ולרוחב.

## מבנה הממשק
- סרגל כלים שמאלי למגע.
- משטח עבודה מרכזי.
- פאנל מקצועי ימני.
- סרגל פרופילים תחתון.
- השוואת לפני/אחרי עם מחיצה נגררת.

## מנועים
- מנוע מקומי ללא רשת.
- שכבת חיבור למנוע AI דרך endpoint חיצוני.
- fallback מקומי כאשר השרת אינו זמין.

## הערה
האייקון המצורף זמני עד לעיצוב האייקון הסופי.
