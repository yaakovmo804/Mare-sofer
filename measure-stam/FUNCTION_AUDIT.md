# ביקורת תפקודית — מדידאות

עודכן: 2026-08-01

המסמך מתאר מה האפליקציה עושה בפועל. הוא אינו מסיק שכלל מקצועי קיים כאשר המערכת מבצעת רק סימון, תיוג או מדידה ידנית.

## רגעים / אמן

| רכיב | מצב | הפעולה בפועל |
|---|---|---|
| רוחבים | ידני | קו בן שתי נקודות; ערך בפיקסלים ובעובי קולמוס לאחר כיול. אין עדיין השוואת משפחת אותיות. |
| גבהים | ידני | קו בן שתי נקודות. אין עדיין מנוע משפחות או סף חריגה. |
| עובי קולמוס | מסייע | זיהוי אוטומטי, קו ידני ובדיקת אזור; התוצאה דורשת אימות משתמש. |
| ישרות | מסייע | סריקת תחום, סיווג אנושי של ב׳/כ׳/נ׳ וקו ייחוס רק לאחר האישור. |
| משקלים | ידני | עובי מקומי בן שתי נקודות; אין מפת משקל של איבר. |
| מרווחים | מעורב | סימון ידני לכל הסוגים; זיהוי אוטומטי ממשי קיים לבין השיטין. |
| איזון לובן | ידני | שטח פוליגון סגור. אין עדיין יחס אוטומטי או כלל 10% פעיל. |
| מרכז אופטי | מידע | אין אלגוריתם מספרי. הכרטיס מציג זאת במפורש ואינו מתחזה לכלי פעיל. |
| מרפסות | ידני + השוואה | שתי נקודות, סיווג ו׳/ת׳ וחציונים. אין עדיין סף תקין/חריג. |
| נטיות ומקבילות | מסייע | סריקת תחום, מועמדי ירכות, זווית חתומה וסיווג אנושי ד׳/ה׳/ת׳. מדידה ידנית נשארת זמינה. |

## כלים נוספים

| רכיב | מצב | הפעולה בפועל |
|---|---|---|
| קעסטעל | פעיל | מסגרת, שלישים, גבולות גג/חלל/מושב והצעת עובי קולמוס. הזיהוי היוריסטי וניתן לתיקון ידני. |
| גג–מושב | מעורב | משתמש בגבולות קעסטעל אם קיימים, או מקבל סימון ידני. |
| עיגול / אליפסה | פעיל | רוחב, גובה ושטח. |
| גג / מושב / ירך בתיבת הקטגוריה | תיוג בלבד | משנה משמעות וצבע של מדידה קיימת; אינו מפעיל זיהוי. כך הוא מסומן גם בממשק. |
| שמירת פרויקט | פעיל | JSON עם תמונה, כיול, גאומטריה, סיווגים, וקטורים וקנבה. |
| ייצוא תמונת מקור | פעיל | מייצא את הצילום, הסימונים ותוויות התוצאה שהמשתמש לא הסתיר. |
| קנבה | פעיל | עותקים נקיים, רקע, שינוי גודל, שכפול, מחיקה וייצוא. |

## קלט עט ואצבע

- כפתורים, לשוניות, בחירות, סרגלים, תיבות סימון, צבע, קובץ וגלילה מקבלים עט, אצבע או עכבר.
- אין מצב ידני של „עט / אצבע”.
- רק שדה שמקבל טקסט או מספר דוחה מיקוד מן העט, כדי למנוע Scribble ומקלדת. אצבע ומקלדת ממשיכות לפעול בו.
- משטח העבודה נשאר משטח דיוק; שתי אצבעות משמשות להזזה ולזום.

## וקטור של אות מצולמת

- מסלול הצילום נשמר כ־Bézier סגור. דגימה קטנה מוגדלת עד פי 2 לפני העקיבה, והפישוט נעשה לפני יצירת העקומות כדי להפחית מדרגות פיקסלים.
- „מבנה” מציג רק תחנות שנקשרו לעוגן אמיתי במתאר. בירך עשויות להופיע: שני צדי החיבור, שני צדי ההצטמצמות אם זוהתה, שני צדי ההתעגלות אם זוהתה, ושני צדי הסיום.
- תחנה שאינה קיימת בגאומטריה אינה מומצאת.
- „איברים” אינו מחלק עוד עוגנים לפי מספרם. ירך מזוהה מקבלת `organId`, תת־מסלול סגור ועוגנים במרחב שמות עצמאי; שתי ירכות אינן חולקות עוגנים.
- למסלול הירך שתי נקודות חיבור מפורשות אל מסלול הבסיס. גשר החיבור מחבר ביניהן גם אחרי הזזה, בלי לשכתב את מתאר האות או את מתאר הירך.
- הקפה של ירך מזוהה נצמדת לתת־המסלול שלה ושומרת את `organId` גם בגרירה הבאה. הקפה אחרת בוחרת רק את העוגנים שבתוכה.
- הזזת איבר שומרת את המרחקים בין עוגניו ומשנה רק את תת־המסלול שלו. מסלול המקור, מסלול הבסיס וכל העוגנים שמחוץ לאיבר נשארים זהים.
- הטיית ירך היא סיבוב קשיח סביב מרכז החיבור לגג, ולא shear. אורכי האיבר והמרחקים הפנימיים נשמרים.
- „עותק” ו„מקור פעיל” משתמשים באותו וקטור. מקור פעיל הוא החלפה חזותית לא־הרסנית בתוך הפרויקט, עם Undo ואיפוס לצילום.

## דברים שאינם מוצגים ככלי פעיל

- השוואת משפחות לרוחב ולגובה.
- אלגוריתם מרכז אופטי.
- מפת משקל של איבר.
- כלל אוטומטי לאיזון לובן או לספי חריגה.
- כלי השבחת צילום כגון בהירות, ניגודיות, חידוד, סיבוב או חיתוך.
- נוסחה אוטומטית המקשרת רוחב, קעסטעל, מקום יציאת איבר ומשקל.

כל אחד מן הסעיפים האלה דורש הגדרה מקצועית או דרישת מוצר נפרדת; הוא אינו אמור להיראות בממשק כאילו הוא כבר פעיל.

## תנאי קבלה שנבדקים בקוד

- כל תחנת ירך מבנית מפנה לעוגן קיים במתאר.
- איבר אינו נוצר בלי קשת מתאר בבעלות בלעדית ושתי נקודות חיבור תקינות.
- ירכות סמוכות אינן חולקות מזהי עוגן.
- תרגום וסיבוב קשיחים שומרים מרחקים פנימיים ואינם משנים את מסלולי המקור, הבסיס או עוגנים חיצוניים.
- ייצוא תוצאה מכבד את מצב הצג/הסתר של התווית.
- גרסאות ישנות של פרויקט ווקטור נשארות ניתנות לטעינה.
