# מראה סופר — קצב הקריאה של הכתב

פיילוט נפרד וניסיוני שממיר את המרווחים החזותיים בכתב למקצב קולי.

## מה עובד בגרסה 0.1

- העלאת צילום כתב מקומי.
- סימון ידני של תחנות לפי סדר הקריאה.
- גרירת תחנות ותיקון מיקום.
- מדידה אופקית או מדידה לאורך המסלול.
- נגינת המקצב לפי היחסים בין המרווחים.
- השוואה לאותו רצף במקצב אחיד.
- מדד אחידות, שלד מקצב ומשך נגינה.
- שמירה אוטומטית במכשיר.
- יצוא/יבוא פרויקט JSON.
- יצוא צילום עם התחנות המסומנות.

## הפעלה

זהו יישום סטטי ללא שרת וללא API. פתחו את `index.html` דרך שרת מקומי, לדוגמה:

```bash
python3 -m http.server 8787
```

ואז גלשו אל:

```text
http://localhost:8787/reading-rhythm/
```

## מודל המקצב

- כל תחנה היא פעימה.
- הזמן בין שתי פעימות יחסי למרחק בין שתי התחנות.
- קצב הבסיס (BPM) מגדיר את ההשהיה הממוצעת.
- במצב "מרחק אופקי" נמדד רק ציר ה־X.
- במצב "לאורך המסלול" נמדד המרחק הישר בין שתי התחנות.
- המקצב האחיד משתמש באותו BPM ובאותו מספר תחנות, כדי לאפשר השוואה ישירה.

## מבנה לשילוב עתידי

קובץ הפרויקט משתמש בסכמה:

```text
mareh-sofer.reading-rhythm / version 1
```

התחנות נשמרות בקואורדינטות יחסיות (0–1), ולכן ניתן לשלב אותן מאוחר יותר באפליקציה הראשית, במדיד אות, במורה סופר או במעבדת ההתערבויות.
